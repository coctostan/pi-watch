<objective>
## Goal

Honor timestamps on supported YouTube references and optional explicit `start` / `end` bounds so transcript, eligible ASR, and visual fallback expose only evidence from one deterministic source-timeline range, together with fixed-size coverage and truncation metadata.

## Purpose

A timestamped long-form URL currently canonicalizes away its requested start and then samples and returns evidence from the full source. Head-only text truncation can therefore omit the section the caller explicitly requested. This plan adds one stateless range contract before Phase 22 changes orchestration order: normalize a range once, apply it consistently to caption/ASR segments and sampled-frame times, and tell callers exactly what range and bounded evidence survived without adding persistence, synthesis, a model dependency, or cloud work.

## Output

- A pure range core for YouTube timestamp parsing, explicit-bound precedence, finite validation, transcript intersection/clipping, and fixed-size coverage summaries.
- Range-aware sampler assembly on the absolute source timeline for normalized captions, eligible ASR output, and visual frame fallback.
- Optional typed `start` / `end` tool parameters in whole seconds, with range/coverage/truncation details that contain no refs or transcript text.
- Deterministic RED/GREEN/REFACTOR evidence across contract, sampler, tool, tier formatting, docs, and exact generated `dist/**` output.
</objective>

## Intent Slice

**Served requirements (verbatim):**

- **R2** — **Sampler data contract** — the in-memory "watched frame set" type: ordered frames (base64 image blocks + resolution tier), per-frame mm:ss timestamps, aligned transcript segments, source metadata (duration, fps sampled, scene-cut vs backfill origin), on one shared timeline.
- **R3** — **Sampler implementation** — ffmpeg scene-change extraction (one frame per cut) + uniform backfill + budget cap (~16 frames default, configurable) + resolution policy (low-res default, high-res for on-screen-text) + paired transcript merge (captions/Whisper) on the same timeline.
- **R5** — **`watch` tool primitive** — takes a **video ref** (a local file path or an explicitly supported YouTube watch/short-link/shorts URL resolved through bounded yt-dlp ownership and cleanup) plus a question, runs the sampler, routes to a tier, and returns an answer.
- **R6** — **Tier adapters** — tier 1 (timestamped transcript delivery), tier 2 (generic OpenAI-compatible sampled-frame vision adapter for local or hosted endpoints), and tier 3 (frames → orchestrator `ImageContent`).
