<objective>
## Goal

Prove that pasted supported YouTube URLs traverse the actual registered `watch` tool and `/watch` command UX, add a default-off real-YouTube smoke test, and give users an accurate setup and troubleshooting path.

## Purpose

Phases 14–15 shipped URL resolution and caption-backed transcript sampling behind the existing sampler seam. This final v0.3 phase closes the user-facing gap: the package boundary must preserve a pasted URL through tool/command registration, offline tests must prove caption-first and visual-fallback behavior without network access, a live smoke must exercise the real resolver/sampler/tool path when explicitly enabled, and Git/local-path installers must know which external binaries and URL forms are supported.

## Output

- Deterministic extension-boundary coverage for the registered `watch` tool and `/watch` command.
- An opt-in real-YouTube Vitest smoke that is skipped by default.
- Committed build output so Pi's default Git-package install can load the manifest-referenced `dist` extension without dev-only build tooling.
- A top-level project README and focused YouTube setup/troubleshooting runbook.
</objective>
