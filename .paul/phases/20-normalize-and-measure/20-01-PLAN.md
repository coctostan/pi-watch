<objective>
## Goal

Establish a deterministic context-efficiency baseline and conservatively normalize overlapping YouTube rolling captions so repeated adjacent cue text is removed without changing timestamps, wording, source attribution, or legitimate repeated speech.

## Purpose

Phase 20 starts M5 at the cheapest pure seam. Current `parseWebVtt()` strips markup but emits every cue payload, so automatic rolling captions can send the same prose to tier 1 multiple times. A test-first, timing-aware transform reduces downstream transcript bytes before Phase 21 range selection and Phase 22 transcript-before-frame orchestration, while preserving the project's local-first, model-agnostic and stateless contracts.

## Output

- A focused pure caption module containing WebVTT parsing and conservative adjacent-overlap normalization.
- A versioned rolling-caption fixture with raw, expected, and byte-baseline evidence.
- Deterministic RED/GREEN/REFACTOR tests for overlap removal, non-overlap preservation, timing/source stability, markup/Unicode handling, and measured byte reduction.
- The existing `parseWebVtt` sampler export and caption effect behavior preserved through `effects.ts`.
- Exact committed `dist/sampler/**` output for Git/local Pi installation.
</objective>
