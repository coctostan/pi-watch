<objective>
## Goal

Implement bounded, explicitly enabled local English ASR as the transcript fallback for spoken questions: preserve captions first, invoke the observed direct `mlx_whisper` executable only when eligible, produce validated timestamped `whisper` segments, surface privacy-safe diagnostics, and retain every existing visual fallback.

## Purpose

Phase 18 turns the evidence-backed Phase 17 contract into the cheapest local transcript path for captionless local files and supported YouTube videos. TDD is load-bearing because the parser, config bounds, eligibility policy, ownership, failure degradation, and single/batch composition all have deterministic input/output contracts, while external process and filesystem effects must stay injected and bounded.

## Output

A focused `src/sampler/asr.ts` pure-core/effect-shell module; typed opt-in ASR config; captions-first sampler composition; spoken-intent extension gating and diagnostics for `watch`/`watch_batch`; deterministic Vitest coverage; and committed exact `dist/**` counterparts for Git/local Pi installation.
</objective>
