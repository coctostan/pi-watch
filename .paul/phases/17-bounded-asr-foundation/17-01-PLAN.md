<objective>
## Goal

Produce an evidence-backed, implementation-ready contract for bounded local English ASR: verify the actual `mlx-whisper` executable and timestamped output shape, measure one temporary model on the target Apple Silicon machine, and decide how `fetchTranscript`, `sample`, `classifyQuestion`, `resolveWatchConfig`, and `watchExtension` should compose without changing production code.

## Purpose

Phase 17 must not encode guessed CLI flags, guessed output, or arbitrary resource defaults into the sampler. A bounded spike makes the external runtime and architecture decisions inspectable before the follow-up TDD implementation plan, while preserving the project's local-first, captions-first, pure-core/explicit-effects design.

## Output

`.paul/phases/17-bounded-asr-foundation/17-01-RESEARCH.md` containing runtime evidence, measured target-hardware observations, the selected boundary design, rejected alternatives, provisional defaults, and exact inputs for Plan 17-02.
</objective>
