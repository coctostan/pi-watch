<objective>
## Goal

Close the bounded M4 audit follow-ups assigned to Phase 23, prove through the manifest-declared compiled extension that transcript-first calls reduce context and perform zero visual decode work, and publish exact v0.5 operator guidance without changing the Phase 20–22 runtime policy.

## Purpose

M5 already normalized rolling captions, made evidence range-aware, and moved transcript routing ahead of visual decoding. Release confidence still has five concrete gaps: `/watch` cannot represent an ordinary quoted local path containing spaces; direct ASR adapter callers can bypass configured duration/timeout ceilings; nested package proof inherits the ambient npm cache; router/tier descriptions still imply semantic inadequacy or native-video ingestion; and the compiled package has no durable product-level efficiency corpus. This plan closes only those gaps and records corpus-scoped measurements rather than adopting the unmeasured 70–90% estimate.

## Output

- A narrowly quoted `/watch` local-ref grammar and direct exported-boundary ASR ceiling enforcement, specified test-first.
- Hermetic nested package proof using a test-owned npm cache and reconciled R4/R6 sampled-frame terminology.
- A small versioned context-efficiency corpus and deterministic registered-`dist` proof with exact context/work evidence.
- v0.5.0 package metadata, operator guidance, and reproducible committed `dist/**` output.
</objective>

## Intent Slice

**Served requirements (verbatim):**

- **R4** — **Router (tier selection)** — decides which tier answers a given question using a defined, deterministic policy: spoken, broad, and mixed spoken/visual questions with a non-empty in-range transcript may start at tier 1; transcript misses and explicitly visual/temporal questions use tiers 2/3; on-screen-text questions select the high-resolution OCR route; broad-only prompts do not enable local ASR, while spoken and mixed prompts retain captions-first ASR eligibility; every route ends in tier 3.
