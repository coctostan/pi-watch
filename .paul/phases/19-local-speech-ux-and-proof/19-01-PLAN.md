<objective>
## Goal

Close v0.4 with an operable local-speech path: commit one bounded deterministic English media fixture, prove the manifest-declared compiled extension through its real registered `watch` tool under both deterministic failure and optional live-ASR paths, publish setup/diagnostic guidance, and reconcile package metadata to v0.4.0.

## Purpose

Phase 18 shipped the bounded local-ASR implementation, but users still need a safe first-run path and maintainers need evidence at the package boundary rather than only mocked source-level tests. This plan proves the already-shipped behavior without changing its architecture: exact opt-in remains mandatory, the default suite remains offline and model-free, a deliberately missing executable must expose a private typed diagnostic and preserve tier 3, and an explicitly enabled live run may prove `mlx_whisper` → timestamped English transcript → tier 1 using the same synthetic fixture. The setup runbook then turns each existing diagnostic into actionable, secret-free remediation while keeping installation and model caches user-owned.

## Output

- A small committed synthetic MP4 plus an inspectable manifest containing its phrase, evidence words, media bounds, generation provenance, and SHA-256.
- One registered-tool acceptance suite that imports the `package.json`-declared compiled extension, validates deterministic fallback/diagnostics by default, and offers a bounded opt-in real-ASR proof.
- `docs/LOCAL-ASR-SETUP.md` and refreshed README guidance for installation, opt-in configuration, diagnostics, privacy/ownership, verification, and limits.
- `package.json` and root lock metadata reconciled to v0.4.0, with the existing committed `dist/**` package boundary verified rather than manually edited.
</objective>
