## Phase Details

### Phase 10: Stand up the model

Local `mlx_vlm.server` runs `mlx-community/Qwen3-VL-8B-Instruct-4bit`; `docs/TIER2-SETUP.md` records uv-pinned setup, server command, smoke test, and `WATCH_TIER2_*` exports. The endpoint returned HTTP 200 for the OpenAI-compatible frames-as-`image_url` request shape.

- Plan: [10-01](../../phases/10-standup-model/10-01-PLAN.md)
- Summary: [10-01](../../phases/10-standup-model/10-01-SUMMARY.md)

### Phase 11: Tier-2 live wire-shape proof

An opt-in, default-skipped Vitest proof sends production `buildTier2Request` output to local `mlx_vlm.server` and confirms `parseTier2Answer` reads a real answer. No production adapter mismatch or per-model branch was needed.

- Plan: [11-01](../../phases/11-tier2-live-proof/11-01-PLAN.md)
- Summary: [11-01](../../phases/11-tier2-live-proof/11-01-SUMMARY.md)

### Phase 12: Tier-2 failure diagnostics

A structured `Tier2Diagnostic` (`unconfigured`, `http-error`, `empty-answer`, `timeout`, `network-error`) is surfaced as `details.tier2` on `watch` and per-item `watch_batch` results through an optional boundary collector. The `null`→tier-3 contract and `tier-runner.ts` remained unchanged.

- Plan: [12-01](../../phases/12-tier2-failure-diagnostics/12-01-PLAN.md)
- Summary: [12-01](../../phases/12-tier2-failure-diagnostics/12-01-SUMMARY.md)
- Merge: PR #14 → `ffe07b3`

### Phase 13: Tier-2 config UX

Single-video `watch` results append a secret-free setup hint only when tier 2 was unconfigured and another tier answered. `WATCH_TIER2_LOCAL=1` opts into the documented localhost endpoint; explicit URL/model configuration wins and the default path remains network-free.

- Plan: [13-01](../../phases/13-tier2-config-ux/13-01-PLAN.md)
- Summary: [13-01](../../phases/13-tier2-config-ux/13-01-SUMMARY.md)
- Merge: PR #15 → `6f26a6f`
