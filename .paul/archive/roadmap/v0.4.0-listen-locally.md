## Overview

v0.4 makes transcript-first routing work for English speech when captions are unavailable. Explicitly enabled local `mlx_whisper` runs only for spoken intent after a caption miss, stays bounded by duration/timeout/output policies, exposes privacy-safe typed diagnostics, owns only adapter-created output, and preserves visual fallback on every failure. Deterministic compiled-package proof and complete operator guidance keep normal tests offline while an exact-opt-in live path remains available.

## Milestone Constraints

- Local ASR is disabled by default and runs only after exact opt-in, spoken intent, and a caption miss.
- Captions remain preferred; ASR never replaces a valid caption transcript.
- Every ASR failure remains private and degrades to the existing visual tier chain.
- Direct external execution is argv-only and bounded by media duration, timeout, and output limits on the registered tool path.
- The adapter owns only its temporary output; media and package/model caches remain caller/user owned.
- Cloud providers remain optional, and normal tests remain deterministic, offline, and model-free.
- `mlx_whisper` and model data are explicit user-managed prerequisites.
- Supported Pi activation is verified; external active-tool governors may require documented allowlisting.

## Milestone Summary

### Key Accomplishments

- Established and measured the real local Whisper executable contract on target Apple Silicon hardware.
- Shipped explicitly enabled, captions-first local English ASR with timestamped tier-1 transcript segments.
- Added bounded resource policy, typed privacy-safe diagnostics, narrow ownership, and visual fallback across every failure path.
- Proved the manifest-declared compiled package through deterministic missing-executable execution without hidden model or network setup.
- Added bounded synthetic speech evidence plus an exact-opt-in live-model correctness path.
- Published complete setup, remediation, ownership/privacy, verification, and limitations guidance.
- Finished with a parent result of 248 passing tests / 3 default-skipped opt-in tests and passing typecheck/build gates; isolated review's ambient npm-cache failure remains routed through F8/R22.

### Key Decisions

- Gate explicitly enabled ASR at the extension for spoken intent only; keep question classification pure and captions first.
- Invoke the configured direct `mlx_whisper` executable rather than embedding Python or performing hidden `uvx` installation.
- Keep package/model caches user-owned and remove only adapter-created output storage.
- Parse unknown Whisper JSON in a pure core and isolate process/filesystem work in a bounded effect shell.
- Expose only typed privacy-safe diagnostics and preserve visual fallback on every ineligibility or failure.
- Prove external-model behavior through deterministic failure at the compiled registration boundary by default; keep real-model proof finite and exact-opt-in.

### Adherence Audit

The mandatory [M4 adherence audit](../../audits/M4-AUDIT.md) completed with one verdict and explicit tagged-evidence/no-test-found record for each stable R1–R22, all document-health lenses, human-selected routes for F1–F17, and explicit author intent re-affirmation after final reconciliation.
